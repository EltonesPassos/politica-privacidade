Política de Privacidade

Última atualização: 17 de novembro de 2026

Esta Política de Privacidade se aplica ao aplicativo Escalas Guitarra, desenvolvido por Elton Passos.

1. Informações Coletadas

O aplicativo NÃO coleta, armazena ou compartilha nenhuma informação pessoal dos usuários diretamente.

2. Armazenamento Local

Utilizamos armazenamento local (localStorage) apenas para salvar suas preferências e shapes personalizados. Esses dados permanecem apenas no seu dispositivo.

3. Permissões

Solicitamos apenas a permissão de áudio para reproduzir os sons das notas de guitarra.

4. Serviços de Terceiros e Anúncios

Este aplicativo utiliza o Google AdMob para exibir anúncios. O AdMob pode coletar e usar dados (como o ID de publicidade do dispositivo) para fornecer anúncios personalizados. Para mais informações, consulte a Política de Privacidade do Google.

5. Compartilhamento de Dados

Não compartilhamos nenhuma informação pessoal, pois nenhuma informação é coletada diretamente por nós. Os dados de anúncios são geridos exclusivamente pelo Google AdMob.
